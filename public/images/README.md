# Organisation des images du site

Chaque dossier correspond à une page ou sous-page du site. Dépose simplement tes images dans le dossier correspondant — pas besoin de format particulier, mais **JPG ou WebP** sont recommandés (plus légers que PNG).

## Arborescence

```
public/images/
├── accueil/                          → Page d'accueil (hero vidéo, portraits, ambiance)
├── leslie-folcarelli/                → Page "Qui suis-je" (bio, palmarès, maestros)
├── pourquoi-le-tango/                → Page "Pourquoi le Tango"
├── contact/                          → Page Contact
├── galerie/                          → Galerie photos/vidéos
│
├── cours-tango-nice/                 → Page Cours (index)
│   ├── collectifs/                   → Sous-page Cours collectifs
│   └── prives/                       → Sous-page Cours privés
│
└── evenements-tango/                 → Page Événements (index)
    ├── milonga-nice/                 → Sous-page Milonga En Tus Brazos
    ├── show-tango/                   → Sous-page Show / Stage / DJ
    └── tango-mariage-nice/           → Sous-page Mariage & entreprise
```

## Conseils

- **Dimensions** : 1920×1080 minimum pour les hero, 1200×800 pour les cartes
- **Poids** : essaye de rester sous 500 Ko par image (utilise TinyPNG ou Squoosh pour compresser)
- **Noms de fichiers** : simples, en minuscules, sans accents ni espaces (ex : `leslie-scene-2024.jpg` plutôt que `Leslie sur scène 2024.JPG`)
- **Format paysage** : privilégier le format horizontal pour les hero
- **Format portrait** : OK pour les photos de profil ou portraits de Leslie

Une fois les images ajoutées, dis-moi — je les intègre dans le code à la place des placeholders.
